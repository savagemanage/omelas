## 연우 조사 회귀의 완전 해소

`84cda53`의 diff는 v2가 지적한 7개 지점을 정확히 겨냥한다. 첫 등장의 `이름은 연우이라 했다`가 `연우라 했다`로, 발화 태그 `연우이 말했다`·`연우이 물었다`·`연우이 등불 곁에 앉았다`·`연우이 잠시 말을 잃었다`가 모두 `연우가`로, 서술문 `연우은 그날 밤`이 `연우는`으로 바뀌었다. `연우`는 모음(ㅜ)으로 끝나므로 주격 `가`, 보조사 `는`, 인용 `라`가 옳다.

```
grep "연우이|연우은|연우이라" books/06-proverbs/chapter-03.md  → 결과 없음
```

장에 남은 15개의 `연우` 출현은 모두 문법적이다. `연우의`(속격)·`연우도`(보조사 `도`는 모음/자음 무관)·노아의 호격 발화 속 `연우`(맞아요, 연우 / 남는 건 없어요. 연우)는 애초에 조사 교정 대상이 아니었다. 인물 연우는 판관기 재판정에서 세례를 옹호하다 서명주에게 패한 젊은 과학자로, 아버지를 병으로 잃은 개인사에서 세례를 자비로 믿게 된 동기가 제시되고, 노아의 "잃을 수 없는 것은 사랑할 수도 없다"는 반론 앞에서 확신이 흔들린 채 돌아가는 호를 그린다.

## 이름 격리와 별이 정본 정합성

하윤은 `books/03-exodus/chapter-04.md` 한 파일에서만 나타나고, 연우는 6권의 인덱스와 3장에서만 나타난다. v1에서 지적된 하윤 이름 충돌과 v2의 연우 격리가 함께 유지된다.

별이는 `canon/story-bible-ko.md`의 §2.7a에 미르(§2.7, 한서린의 개)와 별개 항목으로 등재되어 있으며, "미르의 오기가 아니다"라는 명시적 구분 지침까지 달려 있다. 서사 사용도 이와 일치한다. 창세기 4장에서 별이는 세아 곁의 늙은 개로, 유년기 복음서에서는 데이비드 유년기의 개 혈통으로 세대를 넘어 반향하며, 화면 속 업로드된 데이비드의 목소리를 "정확히 기억하기에 물러서는" 동물의 시선 모티프를 수행한다. 미르(본편)와 시대·주인이 달라 혼동 위험이 없다.

## 분량과 정본 척도

정본 척도(공백·문장부호·마크다운·병기 영문을 제외한 순수 한글 음절 가~힣만 계수, 450자=1페이지)로 측정한 실제 총합은 112,786자다.

```
python3 -c "import glob;print(sum(1 for f in glob.glob('books/*/chapter-*.md') for c in open(f,encoding='utf-8').read() if '\uac00'<=c<='\ud7a3'))"
→ 112786   (≈ 250.6페이지)
```

권당 분포는 12,324(5권 시편)~12,821(1권 계시록)으로 편차가 500자 이내로 고르다. 정본 페이지표(§4)는 합계를 112,787자로 적어 실측과 1글자 차이가 나지만, 목표 서술이 "약 250페이지(약 112,500자 이상)"로 여유를 두고 있어 차단 사유가 아니다.
